# Штаб WiZaRs.UA

Неофициальный фан-сайт клана WiZaRs.UA (Clash of Clans): игроки, войны, ЛВК, рейды, рейтинг, армия.

- Данные обновляются раз в час (GitHub Actions → `scripts/update.py` → `data/db.json`).
- Запросы к API идут через прокси RoyaleAPI, поэтому у ключа API один IP: `45.79.218.79`.
- Ключ хранится в секрете репозитория `COC_API_TOKEN`.
